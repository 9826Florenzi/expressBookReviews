# Express Book Review Application

Server-side online book review application built with **Node.js**, **Express**, **JWT (JSON Web Tokens)**, and **express-session**.

---

## 📚 Features

- **Public Book Access**:
  - Retrieve the full list of books available in the shop.
  - Search books by ISBN, Author, or Title using asynchronous Promise callbacks and async/await.
  - View user reviews for specific books.

- **User Authentication**:
  - Secure user registration with validation.
  - User login utilizing JWT session authorization.

- **Review Management**:
  - Authenticated users can add or modify their personal review for any book.
  - Authenticated users can delete their own review.
